# Aangan Café

A mobile-first café website built with React and Vite.

## Features

- Responsive layout for mobile, tablet, and desktop
- Mobile navigation with a hamburger menu
- Interactive menu category filtering
- Reusable React components and data-driven menu cards
- Click-to-call and WhatsApp customer actions
- Google Maps directions link
- Café highlights, photo gallery, contact section, and footer
- WebP image assets for improved page performance

## Tech Stack

- React
- JavaScript
- CSS3
- Vite

## Run Locally

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
